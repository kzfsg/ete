# ete Phase 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove every model call from ete and replace authoring/healing with an agent-driven session daemon + CLI.

**Spec:** `docs/superpowers/specs/2026-09-14-ete-phase3-agent-sessions-design.md`

## Global Constraints
- No `ai`/`@ai-sdk/*` dependency remains. No API key is read anywhere.
- Step statuses: `passed | failed | skipped`. Report modes: `replay | session`.
- Session state dir: `ete-results/.session/`. Server binds `127.0.0.1` only, token required.

### Task 1: core — Recorder, remove resolver/heal/explore
- Delete `resolver.ts`, `explore.ts`; drop `ai`, `@ai-sdk/anthropic` from core deps. Remove `resolved|healed` from `StepStatus`, `healedFrom`. Runner: drop resolver/heal/ci; missing entry → failed `No recorded action for this step`.
- New `session.ts`: `class Recorder { constructor({driver, name, flow, testPath, resultsDir, prefix?: {steps: Step[], entries: ResolvedEntry[]}}); act(entry, opts?: {as?}) → StepResult; expect(assertion, opts?: {as?, record?}) → StepResult; undo(); steps(); finish() → {report, test, resolved}; abort() }`. `StepResult = { ok, recorded, error?, telemetry?, step? }`.
- Tests with FakeDriver per spec §5. Commit.

### Task 2: cli — session server + client + commands
- `src/session/server.ts` `startSessionServer({cwd, cfg, name, flow, testPath, from?, at?, driver?}) → {port, token, close}`; routes: `GET /status`, `POST /observe|/act|/expect|/undo|/save|/abort`. `POST /act` body `{entry, as?}`; `/expect` `{assertion, as?, record?}`; all mutating routes return `{result, observation:{url, a11yTree, screenshot}}`.
- `src/session/client.ts`: `readServerInfo(cwd)`, `call(cwd, path, body)`, `isAlive(pid)`.
- `src/commands/session.ts`: parse `act`/`expect` argv into entries; `serve` (hidden) runs the server + writes `server.json`; `start` spawns `serve` detached and waits for readiness; printers for observations.
- Tests: in-process server against fixture (full authoring loop → save → `runCommand` passes; failed act not recorded; `--from --at` replays prefix and merges); daemon lifecycle via `node dist/index.js session start/status/abort` in a tmp project.
- `run`: remove resolver/model; failure hint with resume command. Drop `model.ts`, `explore.ts`, AI SDK deps. Config drops `llm`/`heal`. Commit.

### Task 3: action, skill, init, docs
- comment.mjs: remove healed section; failing line includes `fix: ete session start --from <file> --at N`. Tests updated.
- `ete init`: workflow with commented agent-heal job. README + skill rewritten. Dogfood run. Commit.
