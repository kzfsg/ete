# ete Phase 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Flows, per-step telemetry with anomalies, filmstrips, a scrubbable timeline report, media publishing with a grouped PR comment, and `ete explore` for agent-driven recorded runs saved as replayable tests.

**Architecture:** Extend `Driver` with `beginStep/endStep`; the runner records telemetry per step. The timeline is a static HTML file with inline JS over `report.json` + `video.webm`. The Action publishes `ete-results/` to a media branch and links from the comment. `explore` reuses the driver + runner telemetry with a model-driven step source.

**Tech Stack:** unchanged (TypeScript, Vitest, Playwright, AI SDK, Zod).

**Spec:** `docs/superpowers/specs/2026-09-14-ete-phase2-timeline-design.md`

## Global Constraints

- Phase 1 tests must stay green. All new behaviour test-first.
- Anomaly kinds: `console-error | page-error | request-failed | http-error | dialog`. `http-error` is status >= 500 only.
- Filmstrip: 240px frames, max 12, failed outlined red.
- Media branch default `ete-media`, retention 30 days, `runs/<run_id>-<attempt>/`.
- `Report.mode` is `'replay' | 'explore'`; `Report.flow` always set.
